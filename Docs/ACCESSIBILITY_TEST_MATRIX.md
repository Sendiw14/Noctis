# Accessibility test matrix (Stage 1B, R-14 stays open)

**Status: R-14 is open.** NOCTIS does not claim comprehensive accessibility support. What exists today is partial and is listed below exactly: two settings have code behind them (Button Shapes for text-only buttons, Smart Invert for the two share-card previews), Reduce Motion is read in 108 places (source count, behaviour not run), and the rest is unsupported or unverified. Nothing in this matrix was run on a device. "Simulator" means the iPhone 18 Pro simulator with the setting set through `simctl` or the system preference, screenshots viewed.

Legend for "Today": **code + tested** (a unit or render test exists and passed), **code, screenshots** (viewed on the simulator), **source only** (read in the code, not run), **none** (no code reads the setting; not run).

## Required combinations

- Each setting alone, then with Dark, then with AX5.
- Button Shapes on at AX5: the Paywall footer links already overlap each other and the medical notice in the base build (see R-21 in the review); this is a pre-existing layout problem the setting exposes, recorded and not changed here.
- VoiceOver with the Data management "needs attention" notice shown, and with the Subscription "payment problem" state.

## Devices and tools

Accessibility Inspector audit on each screen; a physical iPhone for VoiceOver, Switch Control reach and Smart Invert; a paired Apple Watch for the Watch pages and complications (the Watch has its own Display settings).
