# APP_RULES.md (v1, main app)
Read before touching any main-app screen (everything after onboarding). Check every screen against every rule.

Scope: R1-R17 are copied from ONBOARDING_RULES.md (v2, Ink & Ivory). Changes are marked **(changed)**. Clauses that name onboarding screens (Welcome, Rhythm, Sample, Health, Notifications, Plan, Goal, Paywall) describe onboarding and are kept only for reference; ONBOARDING_RULES.md still governs onboarding, which stays light-only. R18-R20 are new.

Direction: the main app shares onboarding's flat paper language — paper background, ink text, solid flat accent colors, NoctisCard, NoctisIconTile, NoctisCTA — in system Light AND Dark. No gradients, no glow, no starfield, no atmosphere mesh.

R1 Full-bleed paper. PaperBackground (ivory + 3% grain tile) is the root: ZStack { PaperBackground().ignoresSafeArea(.all); content }. Only content respects safe areas. No bands top or bottom. Hosting view background = ivory. **(changed)** In Dark the paper is the dark `bg` token; "ivory" above means the current mode's `bg`.
R2 Flat and honest. Solid flat shapes only. No glow, blur, aurora, gradient fills on content, or glass on content. Allowed: bottom-stack fade, iOS 26 glass on the back button only (fallback: white circle + hairline), one soft shadow spec (cocoa .06, blur 24, y 8) on floating cards. Nothing clips: no visible rectangles, no hard-edged bands.
R3 Titles never truncate. 3 lines max, minimumScaleFactor .8, fixedSize(horizontal:false, vertical:true). Titles take their natural height; content starts exactly 24pt below the title.
R4 Type. SF Pro Rounded everywhere (.fontDesign(.rounded)). Title 38 bold, tracking -0.6, one emphasized phrase in orangeText. Hero numerals 64-88 heavy, monospacedDigit, contentTransition(.numericText()). Body 17 ink2. Caption 13 ink3. Min text 12. Never italic serif. Dynamic Type: all text scales. Each size above is its value at the default text size (Large) and is anchored to a text style: titles and hero numerals → .largeTitle; body 17, row titles and CTA labels → .body; labels (14–16) → .subheadline; captions 13 → .footnote; small print ≤12 → .caption/.caption2. Hero numerals use Font.system(size:weight:design:) with @ScaledMetric relative to .largeTitle, capped at 1.6x, and shrink to fit a card that still can't hold them. Icons, tiles and marks beside text scale with @ScaledMetric relative to that text, capped at 1.6x; decorative hero graphics stay fixed. At accessibility sizes, rows that sit side by side stack vertically (Welcome trust card, Plan columns, Sample legend, Goal rows, badge rows), and labels wrap rather than truncate. Use noctisFont / noctisNumeral / noctisIcon (DesignSystem/NoctisScaledType.swift).
R5 Palette **(changed)**. Main-app views read `NoctisAppColor` tokens only (adaptive Light/Dark; no hardcoded hex in views). Onboarding keeps the fixed `NoctisPaper` tokens and stays Light.
  Light (the NoctisPaper tokens): bg #F8F5EE, surface #FFFFFF, hairline #E9E3D8, track #ECE6DA, ink #2B1D14, ink2 #6B5B4E, ink3 #7A6B5E, orangeText #C2571A. Fills: sage #9DB073, orange #E07B39, butter #F2CE6B, lavender #A08CEB, cocoa #4A2F22. CTA: cocoa capsule, ivory (#F8F5EE) label.
  Dark: bg #17110E, surface #221A15, hairline #33281F, track #2E241D, ink #F4EDE3, ink2 #C9BBAA, ink3 #9C8C7B, orangeText #F08A4B. Fills: sage #8FA366, orange #E4854A, butter #E9C25E, lavender #9A87E6, cocoa #9A6A50 (approved; #4A2F22 is 1.5:1 on the dark surface). CTA: ivory capsule (#F4EDE3), #2B1D14 label.
  Stage colors: Deep cocoa, Core orange, REM sage, Awake butter. Text on cocoa/ink fills is ivory; text and glyphs on sage, orange, butter and lavender use `onFill` (#2B1D14 in both modes). Unit test contrast in BOTH modes: ink, ink2, ink3 on bg >= 4.5; orangeText on bg >= 3 (display only); CTA label on CTA fill >= 4.5; onFill on each fill >= 4.5; cocoa on surface and on track >= 3 (graphics).
R6 One hero per screen. Every screen with a title starts its content exactly 24pt below the title, on every screen, no exceptions. Never vertically center the content region. Leftover space collects above the bottom stack. Only Welcome (no title) centers its content block optically (1 part above, 2 below). At most 24pt between hero, caption and CTA.
R7 Navigation **(changed, replaces the onboarding top bar)**. The main app uses a system TabView built with the iOS 18 `Tab` API (iOS 26 gets Liquid Glass automatically; never restyle the bar). Tabs in this order: Home (house), Sleep (moon.zzz), Recovery (heart), Insights (lightbulb), Coach (sparkles). Home is the default tab. Profile is not a tab: it opens from a 36pt avatar button at the top right of Home. Every destination has an `AppRoute` case (home, sleep, recovery, insights, coach, profile) so widgets and notifications can deep-link.
R8 Layout is system layout. Use VStack, Grid, ScrollView, ViewThatFits. No .position(), and no GeometryReader-driven absolute placement outside Canvas. No debug overlays, borders, coordinate labels or test colors, ever. Before reporting done run: grep -rn "\.position(\|\.border(\|DEBUG" on the feature sources you touched and justify or remove every hit.
R9 Motion budget. One hero animation per screen (<= 1.2s). Everything else is a 12pt rise with 60ms stagger (.settle). Reduce Motion: 0.2s fades only. Haptics via NoctisHaptics only.
R10 CTA. Cocoa capsule, 58pt (at the default text size; it grows with its label, never clipping it), ivory 17 semibold label + trailing arrow.right, press = scale .97 with spring return, loading = label morphs to a ring, disabled = track fill + ink3 label. Secondary = 44pt text button in ink2. Bottom stack pinned with safeAreaInset(.bottom) over a paper fade so scrolling content slides under it. At AX sizes content scrolls and the CTA stays pinned. **(changed)** In Dark the capsule is ivory (#F4EDE3) with a #2B1D14 label (`NoctisAppColor.ctaFill` / `ctaLabel`).
R11 Self-verify. After each screen: build, run on iPhone 17 Pro, capture with `xcrun simctl io booted screenshot /tmp/<screen>-<variant>.png`, then LOOK at the images. Variants: 17 Pro, iPhone SE, AX3 (`xcrun simctl ui booted content_size accessibility-extra-large`), plus every state named in the screen prompt. **(changed)** Also capture Dark (`xcrun simctl ui booted appearance dark`). Fix until R1-R10 pass. Report one pass/fail line per rule. Never say done without screenshots.
R12 Performance. 60fps. One TimelineView per screen at most. Pause when scenePhase != .active or Reduce Motion.
R13 Honesty. Never fabricate health data. Sample data is always labeled "Sample". No fake urgency, scarcity or countdowns. Paywall shows real StoreKit prices; close and Restore are always visible.
R14 Scroll edges. **(changed)** Content never renders behind the status bar: main-app scroll views without a navigation bar use `noctisStatusBarGuard()` (iOS 26+: `.scrollEdgeEffectStyle(.soft, for: .top)`; iOS 18: a paper scrim, solid under the status bar and fading out over 16pt). (a) ScrollView must never clip card shadows: use .scrollClipDisabled() with horizontal padding inside the scroll content (or contentMargins). No shaded rectangle may appear behind card groups. (b) The bottom fade (24pt paper-color gradient above the CTA stack) renders ONLY when content actually extends below the visible area; the top fade (24pt paper-color gradient under a pinned header/title) renders ONLY when content has scrolled up under it. Drive both with onScrollGeometryChange. When content fits, there is no fade. Neither fade may show a grey band, and a partially scrolled-away card must fade out completely (including its shadow) rather than leave a sliver. The last piece of content clears the CTA stack by 16pt when fully scrolled. Text may never render half-faded at rest. At accessibility sizes, stacked text blocks sit at least 28pt apart (fade + 4) so a resting fade can always fall between them.
R15 Consistency. NoctisCard inner padding is always 20pt. Stacked cards are always 12pt apart. **(changed)** Main-app screens: 20pt side margins and stacked cards 16pt apart (`NoctisAppCard`). One documented exception, the compact card (`NoctisPaperCard(density: .compact)`): 14pt vertical padding (horizontal stays 20pt) and 8pt between stacked cards, allowed only on Health and Notifications so they fit per R16. Goal names use sentence case everywhere ("Better sleep", "More energy").
R16 Fit **(changed)**. Main-app screens scroll. On iPhone 17 Pro at the default text size, each screen's most important element (e.g. Home's recovery score or state) is fully visible without scrolling.
R17 Digits. monospacedDigit only on numbers that animate. Static text like "Bedtime around 11:00 PM" uses proportional digits.
R18 Data honesty **(new)**. Every number on screen comes from an engine with a unit test. No number is hardcoded or estimated in a view. Missing data shows a stated empty state, never a placeholder number.
R19 No dead ends **(new)**. No button or row may lead to an unbuilt feature. Unbuilt tabs show a simple "Coming soon" view and are listed in ROADMAP.md. ROADMAP.md must be empty before release.
R20 Architecture **(new)**. Views only read a view model's snapshot. No HealthKit calls, date math or scoring inside views.
