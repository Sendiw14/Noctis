# QA ledger

QA part 1: release hygiene, data safety, stability. Not fast mode.

**Rules.** Every finding has a row and keeps it after it is fixed (with the commit hash). A row says PASS only with evidence: a test name, command output, or a screenshot path that was actually viewed. Anything not verified is UNVERIFIED with the reason. Statuses: OPEN, FIXED, PASS, ACCEPTED (justified), UNVERIFIED. Severity: blocker / major / minor (`info` for a check that passed).

**If interrupted:** read this file, find the first unchecked step in the checklist, and continue; never redo a finished step. The helper script is not part of the repo; rows are plain Markdown.
